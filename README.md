# Евклид — адаптивный сайт проектной компании

Учебный проект, выполненный по макету в рамках обучения в **Skillbox**. Цель работы — практика семантической HTML-разметки, адаптивной вёрстки и реализации интерактивных элементов на JavaScript.

> Проект создан в учебных целях и не является официальным сайтом реальной компании.

## Возможности

- Адаптивная вёрстка для разных размеров экрана.
- Слайдер на первом экране на базе Swiper.
- Переключаемые вкладки в разделе этапов работы.
- Аккордеон с вопросами и ответами.
- Мобильное меню и раскрывающаяся форма поиска.

## Технологии

- **HTML5** — структура страницы.
- **CSS3** — оформление, Flexbox, медиазапросы.
- **JavaScript** — интерактивные элементы.
- **Swiper 8** — слайдер.
- **Accordion** — раскрывающиеся блоки.
- **БЭМ** — подход к именованию CSS-классов.

## Запуск локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/roman-werstka/ewklid.git
   ```
2. Перейдите в папку `ewklid`.
3. Откройте `index.html` в браузере или запустите через Live Server в VS Code.

Для загрузки Swiper и некоторых внешних ресурсов требуется доступ к интернету.
